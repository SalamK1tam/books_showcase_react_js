# 📚 Books Showcase (React)

Простое React-приложение-каталог для демонстрации списка книг с фильтрацией и асинхронной загрузкой данных.

---

## Описание

Это SPA, в котором реализованы:

* асинхронная загрузка списка книг
* отображение каталога
* фильтрация/сортировка по состоянию
* передача данных через props
* базовые примеры работы с компонентами

---

## Стек

* React
* JavaScript
* Vite
* Tailwind CSS

---

## Установка и запуск

```bash
git clone https://github.com/SalamK1tam/books_showcase_react_js.git
cd books_showcase_react_js
npm install
npm run dev
```

Откроется на:

```text
http://localhost:5173
```

---

## Структура проекта

```bash
src/
  App.jsx               # корневой компонент
  data.js/              # хранит массив с книгами
  index.css             # стили
  main.jsx              # точка входа
  FilterButtons.jsx     # кнопки фильтрации
```

---

## Основная логика

Приложение делает примерно следующее:

* загружает список книг (симулируя запрос)
* отображает книги в списке
* позволяет фильтровать / сортировать
* компоненты получают данные через props

Это стандартный подход для SPA-приложений на React с клиентской логикой отображения.
